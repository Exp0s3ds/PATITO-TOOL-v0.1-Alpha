# PATITO TOOL

⚠️ ADVERTENCIA IMPORTANTE ⚠️

🚫 USO RESPONSABLE Y LEGAL

Este programa utiliza un Token de Bot de Discord con permisos de ADMINISTRADOR para realizar acciones como crear canales masivamente, enviar mensajes en bucle, borrar canales, roles y expulsar/banear miembros (RAID y NUKE).

❌ Lo que NO debes hacer:

NO uses esto en servidores donde NO tienes permiso explícito del dueño
NO uses esto en servidores públicos, comunitarios o ajenos
NO uses esto para atacar, molestar, destruir o dañar servidores de terceros

⚠️ Consecuencias reales:

🚫 Tu cuenta de Discord puede ser SUSPENDIDA o ELIMINADA permanentemente
🚫 Tu IP puede ser bloqueada por Discord
🚫 Puedes enfrentar consecuencias legales por daños informáticos, destrucción de datos o ataques a servicios digitales
🚫 El bot puede ser detectado y baneado instantáneamente por los sistemas de seguridad de Discord

⚠️ Discord tiene límites de velocidad y sistemas de detección automática — enviar mensajes a velocidad 0 puede hacer que el bot sea baneado inmediatamente o que el token quede invalidado en segundos
